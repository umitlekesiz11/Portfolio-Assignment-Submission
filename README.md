# Umit Lekesiz GitHub Repositories

This README file contains information about selected repositories from [Umit Lekesiz's GitHub account](https://github.com/umitlekesiz11?tab=repositories).

## Repository List

### [ASP.NET-MVC-Entity-Framework](https://github.com/umitlekesiz11/ASP.NET-MVC-Entity-Framework)
A project demonstrating the implementation of ASP.NET MVC architecture with Entity Framework. This repository showcases how to build web applications using the Model-View-Controller pattern integrated with Entity Framework for database operations.

### [Polymorphism-Assignment-Submission](https://github.com/umitlekesiz11/Polymorphism-Assignment-Submission)
This repository contains assignment solutions focused on polymorphism concepts in object-oriented programming. It demonstrates the implementation of inheritance, method overriding, and dynamic method dispatch.

### [Operators-Assignment-Submission](https://github.com/umitlekesiz11/Operators-Assignment-Submission)
A collection of assignments related to operators in programming. This repository includes examples and implementations of various operators such as arithmetic, logical, relational, and bitwise operators.

### [Method-Class-Assignment-Submission](https://github.com/umitlekesiz11/Method-Class-Assignment-Submission)
This repository contains assignments focused on methods and classes in object-oriented programming. It demonstrates the implementation of class structures, method definitions, and object interactions.

### [Final-Assignment-Submission](https://github.com/umitlekesiz11/Final-Assignment-Submission)
A comprehensive project representing the final assignment submission. This repository showcases the application of various programming concepts and techniques learned throughout the course or program.
